# Examples

Both examples connect a Rust egui GUI to either a Python or Rust server.

- [Counter](counter/README.md): start here for a shared count and reset signal
  in a small native GUI.
- [Showcase](showcase/README.md): explore state types, collections, buffers,
  and images in a native or browser GUI.

Each guide includes run commands and links to the source code.

Tests for both examples live in [`tests/`](tests/README.md), with separate Python
and Rust suites.
